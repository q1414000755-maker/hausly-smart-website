# Hausly Smart Website

Website source, catalog data and referenced media. This repository is not connected to automatic production deployment.

## Local preview

Run `node server.cjs` and open the address printed in the terminal.

## Product detail pages

Run `node build-product-detail-v2.cjs` to rebuild the 92 catalog-bound routes. See `PRODUCT-DETAIL-V2.md` and `product-detail-v2-manifest.json`. The standalone M6 design preview is also retained.

## Product data

Source records are under `legacy-products/_data/`. Browser catalog artifacts are under `assets/js/` and `legacy-products/assets/js/`. Keep source records and generated catalogs consistent when editing product information. Missing product photography and wiring documents remain explicitly marked pending.

Design drafts, screenshots, original private backups, source documents, credentials, logs and dependency caches are excluded.
